# Music Release Manager

Music Release Manager is a Codex plugin for independent artists and record labels. It helps organize the release of a song, single, EP, or album from final audio, artwork, metadata, and distributor delivery through editorial pitching, lyrics, smart links, social content, advertising, press, radio, and release-day follow-through.

This plugin is for **music releases**, not software or app releases. For artists working in Norway, it also helps turn common release, rights, funding, and capacity questions into a short, prioritized plan, while requiring current verification for deadlines and eligibility.

It starts with a blank release record. It does not contain any artist's private release files or assume that a previous release's dates, credits, identifiers, contacts, or links apply to a new one. It prepares and checks work; submissions, public posts, outreach, and spending require specific authorization.

By Elvic Records, part of Elvic Gruppen AS.

## Install in Codex

```sh
codex plugin marketplace add elvic-group/release-manager
codex plugin add release-manager@elvic-records
```

Start a new Codex task after installation and ask: “Help me plan a music release.”

## What's included

- A general release-management skill and practical workflow references, including Norway-specific artist support
- A plugin marketplace manifest for installation
- The Release Manager logo

This plugin is an assistant workflow, not a distributor or a guarantee of editorial placement, publication, or promotion results. Always confirm current platform requirements before submitting.
