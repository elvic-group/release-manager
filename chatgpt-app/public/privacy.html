Privacy Policy

Effective date: 19 September 2026

Music Release Manager processes only the details and draft content a user chooses to include in a tool request, such as artist and release information, biographies, release copy, social captions, image prompts, proposed form-field values, campaign goals, markets, budget proposals, landing-page details, and checklist answers.

When a user supplies an audio file for the Audio Analysis tool, the service temporarily downloads that file only to measure its technical properties and embedded tags. It does not retain the audio in a database; the temporary working file is deleted before the result is returned. The tool does not edit a master, submit a release, publish content, or access artist accounts.

The service does not require an account, does not access Spotify, social-media, or advertising accounts, and does not store artist tool inputs or results in a database. When funding catalog updates are enabled, the service stores only public support-program records and source-check results, such as an official source URL, check time and response status. Runtime infrastructure may produce short-lived operational logs needed for reliability and security; these logs are not used for advertising or sold to third parties.

Do not enter passwords, payment information, government identifiers, private listening credentials, or other unnecessary sensitive information.
